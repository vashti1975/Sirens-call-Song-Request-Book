Siren's call Song Request Book 1.3.4

NORMAL INSTALL
Add this URL under /xlsettings > Experimental > Custom Plugin Repositories:
https://raw.githubusercontent.com/vashti1975/Sirens-call-Song-Request-Book/main/pluginmaster.json
Enable and save the repository. In /xlplugins install Siren's call Song Request Book. Choose SongbookSync for a configurable hosted book, or the compatible TramaticSync variant for the existing Tramatic installation. Use one companion on your lead bard and keep MidiBard 2 enabled.

MIGRATE FROM DEV TOOLS
Disable the development copy and remove its Dev Plugin Locations entry before enabling the normal installation. Keep connection.json and your old files locally. The TramaticSync variant preserves its internal identity, /tramaticsync command, endpoint and saved key format. No replacement key is required when the existing configuration is present.

PAIRING
General companion: /songbooksync HTTPS_URL TOKEN
Tramatic companion: /tramaticsync TOKEN
Copy the full command from your owner page. Do not share it. Routine issues: use Refresh connection in the songbook, enable both plugins, and start a new song. Use /songbooksync status or /tramaticsync status as appropriate.

Say announcements can be disabled with the corresponding command followed by announcements off. The setting is saved.

BUILD AND VALIDATION
Requires .NET 10 and Dalamud API 15 libraries. See docs/PLUGIN-INSTALLER.md and the Windows workflow. Installer packages contain only the compiled companion, matching manifest and AGPL license. They do not bundle MidiBard. Actual Playing now, request completion, /s delivery, pause/resume and replay behavior must still be verified inside FFXIV.
